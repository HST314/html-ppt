# 图三：双景叙事纪念徽章

## 视觉描述

![图三](images/图三_双景叙事纪念徽章.jpg)

### 整体风格
历史叙事感 × 双重视觉并置

### 构图分析

- **左侧徽章**：采用高浮雕银币工艺，表面呈现强烈的明暗对比。中央为长征八号甲火箭，两侧分别浮雕空间站/卫星与祥云纹饰，底部火焰以渐变金色呈现。徽章边缘有细密的齿纹，增强金属质感与收藏仪式感。
- **右侧实景卡**：竖版构图，真实火箭在星空背景下发射，尾焰照亮夜空，上方以粗体金色字标注"长征八号甲"与"千帆星座"，明确任务主题。实景卡边缘有暗色描边，与左侧徽章形成"设计稿→实物"的对应关系。
- **背景氛围**：整体背景为深紫蓝色星空，散布金色星点与光斑，营造"历史时刻"的庄重与辉煌感。徽章与实景卡的光源方向一致（均从左下向右上），确保视觉统一。
- **色彩体系**：银白（浮雕高光）+ 炭黑（浮雕阴影）+ 炽金（火焰/标题）+ 暗紫蓝（背景），整体色调沉稳、具有档案感。

### 象征意义
左侧徽章代表"设计的理想"，右侧实景代表"实现的现实"，两者并置构成完整的航天叙事——从蓝图到星辰。浮雕工艺本身即是对历史时刻的"铭刻"。

### 工艺特征
- 工艺：高浮雕银币工艺，浮雕深度达1.2mm以上
- 边缘：细密齿纹，增强收藏仪式感
- 火焰：渐变金色处理，从橙黄到炽白过渡
- 实景卡：印刷品，覆哑光膜，边缘暗色描边
