# FINAL QUALITY CHECK（最终质量审查）

本文件定义 html-deck 的**终审层**：每页生成后、交付前，必须逐页执行「四维检查清单（15 条）」与「二次升级判断」。既有 `QA_RUBRIC.md` 是 100 分制评分与专项量化检查；本文件是其后的**逐页终审回路**——四维检查发现问题 → 处置动作修复 → 二次升级判断再优化 → **修改后重新执行四维检查**，形成闭环。

与其他文档的分工（互不替代；本文件对所有既有口径均为**引用关系**，判定标准引用既有量化阈值，仅在没有既有口径时才新立）：

- `QA_RUBRIC.md`：100 分制评分、专项量化检查（文本与符号层 / 布局稳定 / 场景多样性）与 Deck 级阻断门禁——本文件是评分通过后的终审回路，四维条目的判定口径直接引用其量化项。
- `layout-patterns.md`：版式签名连页检查（连页变体禁令、节奏配额）——设计维「连续页面同质化」的判定口径。
- `design-scenario-system.md`：10 类业务场景 + 1 个骨架保留项 `目录页(toc)`、场景五属性量规——设计维「是否符合页面场景」的判定口径。
- `spatial-storytelling.md`：六组空间关系、默认阅读向量——逻辑维「空间是否帮助理解」「是否存在阅读路径」的判定口径。
- `visual-symbol-system.md`：七类符号、四种语义职能、§8 纯装饰三测试——逻辑维「符号替代文字」与视觉维「视觉污染」的判定口径。
- `THEMES.md`：双色分工与深色主题配色纪律——视觉维「字体颜色 / 背景冲突 / 配色协调」的判定口径。
- `page-logic-patterns.md` §17：文本内部升级与符号视觉引导（§17.5 残留文本清理）——内容维「无关文字」与二次升级「强化关键词」的执行口径。

触发时机：执行流程总线第⑦步（质量检查），在既有 QA 评分通过后逐页执行；审查结果逐页登记 `state/qa_report.md` 终审节（页码 / 四维 15 条结论 / 二次升级结论 / 修改记录）。**任一页缺终审登记即 QA 判失败**（SKILL.md 阶段 5 终审门禁）。

## 1. 四维检查清单（15 条 · 逐页强制）

每条 = 检查问题 + 可执行判定标准 + 命中后的处置动作。命中即处置，处置后重查本条；全 15 条通过方可进入二次升级判断。**标注【终审阻断】的条目命中即整页不通过**（不是扣分项），必须修复后重审。

### 1.1 内容维（3 条）

**C1. 是否存在无关文字？**

- **判定标准**：逐页核对——出现与页面叙事任务无关的句子（模板腔、占位列、串场词），或水印 / eyebrow / meta-line 与当页主题无关、含无意义词（DECK / LOREM 等），即命中。口径引用 `page-logic-patterns.md` §17.5 残留文本清理与 `QA_RUBRIC.md`「文本与符号层检查」残留文本项（判不合格）。
- **处置动作**：删除该文字，或重写为与当页主题一致的项目相关内容；改后重查本条。

**C2. 是否可以删除内容？**

- **判定标准**：对页面每个内容块跑「删除测试」（`visual-symbol-system.md` §8 测试 2 同口径应用于文本块）——删掉它，观众对本页主结论的理解不受损（"看着更饱满"不算损失）→ 命中可删；同时对照场景卡信息密度档（`design-scenario-system.md` §2 四档量规），实测条目数 / 字数超出当页场景密度档上限 → 命中。
- **处置动作**：删除该内容块，将页面信息密度降回场景卡档位；内容总量超上限时先拆页，禁止压缩字号硬塞（沿用 `QA_RUBRIC.md` 布局稳定项「字体不可异常缩小」）。

**C3. 是否只有一个核心结论？**

- **判定标准**：本页主结论唯一（`state/page_semantics.md`「主结论」列只有一句话）；页面出现 ≥2 个并列核心判断，或 takeaway 与首条 bullet 逐字相同（机械复制）→ 命中。口径引用 `SKILL.md` 五步判断之「主结论」（写不出主结论的页回炉拆页或并页）与 `QA_RUBRIC.md` 结论条真实性项。
- **处置动作**：多结论页拆页（一个结论一页）；takeaway 重写为本页主结论的复述或收束（`So-what：` 开头，`page-logic-patterns.md` §17.3 结论条纪律）。

### 1.2 视觉维（5 条）

**V1. 字体颜色是否易读？**【终审阻断】

- **判定标准**（量化门槛，逐项测量，任一不满足 → 命中）：
  1. 正文 / 背景对比度 **≥4.5:1**；深色底有效文字透明度不低于白色 45% 档（四档 100% / 72% / 55% / 45%）；1920 画布基准下正文 `getComputedStyle` 字号 ≥14px。
  2. **大标题**（h1/h2/action title、`.num` 大数字焦点等标题档字号元素）与背景对比度 **≥3:1**。
  3. **近似色禁令**：任一文字 / 强调件（含 `.hl` / `.num` / 编号徽章 / 标签）与其**直接承载面**（卡片底色、accent 填充面、图片压字区）的对比度 **<3:1**，或前景色与承载面为同一 token / 同一色值（典型：accent 色高亮文字压在 accent 填充面上，对比度 ≈1:1）→ 直接命中，不论正门槛是否通过。
- **口径引用**：`QA_RUBRIC.md` 对比度硬指标与「字体不可异常缩小」、`THEMES.md` 深色纪律 2（文字透明度阶梯）。
- **处置动作**：文字提升透明度档位或改用 `--text` / `--muted` token；近似色命中的强调件改 `--on-accent` 深墨（或改承载面色），禁止同 token 前景压同 token 背景；字号不达标先拆页或删内容（走 C2），禁止缩字硬塞。改后重查本条。

**V2. 背景与文字是否冲突？**

- **判定标准**：accent 填充面上的文字必须为 `--on-accent` 深墨——白字压浅金（对比度约 2.4:1）直接命中；文字压图处无 scrim / 遮罩处理 → 命中。口径引用 `THEMES.md` 深色纪律 3（accent 面反色文字）、`QA_RUBRIC.md` 对比度项与美学首因比对（图片遮罩 / 说明条）。
- **处置动作**：反色文字改 `--on-accent`；压图文字加 scrim 压字层（做法见 `design-scenario-system.md` §3.1 封面页）或将文字移出图区。

**V3. 配色是否协调？**

- **判定标准**：全页只走双色分工——accent = 强调与焦点、accent-2 = 结构与引导，出现第三强调色 → 命中；内容页未共享同一 `--bg`、一套 deck 背景色超过 1–2 种 → 命中；主题文件内出现与本主题无关的硬编码 hex/rgba → 命中。口径引用 `THEMES.md` 深色纪律 5（双色分工）、1（背景色上限）、4（token 派生禁硬编码）。
- **处置动作**：第三强调色归并到 accent 或 accent-2（按职能归位）；逐页换底的背景归并回 `--bg`（封面 / 尾页仅允许同色系加深变体）；硬编码色改写 `color-mix(in srgb, var(--accent) …)` 派生。

**V4. 是否视觉污染？**

- **判定标准**：逐页对每个线条 / 符号跑纯装饰三测试（语义测试 / 删除测试 / 锚点测试，锚点测试按线型选款），命中任一即视觉污染；每页符号体系 >2 种同判命中。口径引用 `visual-symbol-system.md` §8（判定标准与正误示例）与 §0.3（用量纪律）。
- **处置动作**：命中符号删除，或改造为承担四种语义职能之一的语义符号（七类符号内）；符号体系超 2 种先减符号再落版。扣罚走 `QA_RUBRIC.md` 符号语义核对项（纯装饰符号每页扣 5 分）。

**V5. 结构类符号是否达到每页下限？**【终审阻断】

- **判定标准**：内容页结构类符号实例（`visual-symbol-system.md` 七类——编号 / 箭头 / 节点 / 路径 / 连接线 / 标签 / 标记，且通过 §8 三测试非纯装饰）**≥2 个**，其中 **≥1 个承担方向或关系职能**；骨架页（封面 / 章节 / 目录 / 尾页）**≥1 个**。数量不足、全页无任何结构类符号、或计入的符号过不了 §8 三测试 → 命中。口径引用 `visual-symbol-system.md` §0.4（产出下限）。
- **处置动作**：按 `visual-symbol-system.md` §9 配套表与本页登记的正文关系补足符号（每页体系 ≤2 种纪律不变）；禁止为凑数贴纯装饰件（凑数件过 §8 测试时必命中 V4）。改后重查本条与 V4。

### 1.3 逻辑维（4 条）

**L1. 空间是否帮助理解？**

- **判定标准**：每页能指认六组空间关系之一（左→右时间推进 / 上→下层级关系 / 中心→周围生态关系 / 外围→中心聚合过程 / 路径线流程 / 对比布局变化），且与 `state/page_semantics.md` 登记逻辑类型命中 `spatial-storytelling.md` §7 衔接映射表；指认不出（方向空转）或空间语义与登记逻辑冲突（并列画成单向路径、层级横放成时间轴等）→ 命中。口径引用 `spatial-storytelling.md` §0.1（方向必须承载逻辑）、§8-1 / §8-5 与 §9 核对点。
- **处置动作**：按二次升级判断「调整空间关系」回路重映射空间关系；空间语义与逻辑类型冲突的页回到总线④ / ⑤ 修正登记与选型。

**L2. 是否存在阅读路径？**

- **判定标准**：页面阅读顺序可沿默认阅读向量（左→右、上→下）一口气读完，无折返、无跳跃；视觉焦点落在空间向量的终点或中心（时间推进最右端 / 层级最上层 / 生态中心核 / 聚合汇聚点 / 流程终点 / 对比结论条）。阅读动线断裂、焦点与向量终点错位 → 命中；逆向量用法未在蓝图「选型理由」登记 → 命中。口径引用 `spatial-storytelling.md` §0.2（默认阅读向量）、§0.5（焦点与空间终点重合）、§8-3（无登记逆向判失败）。
- **处置动作**：重排区块使动线顺向量；焦点块移至向量终点 / 中心并保证焦点可辨识（最大字号 / 最大面积 / 最高对比至少居一）；确需逆向表达"回溯 / 收束"的，在蓝图「选型理由」补登记。

**L3. 是否可以使用符号替代文字？**

- **判定标准**：页面存在「用文字解释结构关系」的段落（如"第一步…第二步…然后…最后"的纯文字链、"A 与 B 相互促进"的纯文字对照、"分为三层"的纯文字层级），且该关系可用七类符号之一（编号 / 箭头 / 节点 / 路径 / 标签 / 连接线 / 标记）承接 → 命中。口径引用 `visual-symbol-system.md` §1–§7（七类符号语义职能）与 §9 符号 × 空间关系配套表。
- **处置动作**：按二次升级判断「增加视觉符号」回路，以符号承接关系语义并删去被替代的解释性文字；遵守每页符号体系 ≤2 种纪律（§0.3）。

**L4. 正文结构是否体现内容关系？**

- **判定标准**：逐页核对 `state/page_semantics.md`「正文关系」列登记（并列 / 递进 / 因果 / 对比 / 总分 / 层级六类，判定口径见 `design-scenario-system.md` §1A），并对照页面实际正文结构——并列页为平等格阵 / 卡列、递进页有编号递增或阶梯、因果页有因 → 果方向件、对比页有双栏对位、总分页有中心核 + 分支、层级页有分层条；**正文退化为无结构段落 / 裸列表平铺（一眼即连续文字行、读不出条目间关系）**，或实际结构与登记关系不符、或「正文关系」列缺登记 → 命中。
- **处置动作**：先补 / 修正「正文关系」登记（回总线④），再按 `design-scenario-system.md` §1A 关系 → 结构映射表重选正文承载结构（走二次升级 U5 / U3 回路）；改后重查本条。

### 1.4 设计维（3 条）

**D1. 是否连续页面同质化 / 全 deck 结构超配额？**【终审阻断】

- **判定标准**：① 连页层——逐页列出布局签名（pattern + 变体），连续内容页签名完全相同 → 命中；≥8 页内容区段版式种类 <5 种，或连续 3 页使用同一 pattern 族 → 命中。② **deck 层（TASK-018 配额）**——逐页登记渲染级视觉结构签名四元组（标题位置 × 内容区切分 × 焦点位置 × 模块节奏，口径见 `html-layout-system.md` §9），四元组 ≥3 维相同即判相同 / 高度相似，同一签名的页面 **>2 页（转场页除外）→ 命中**；仅改配色 / 描边 / 边框的伪变体不算结构差异。口径引用 `layout-patterns.md` 铁律（连页变体禁令、节奏配额、§13 冲突裁决规则 3 连页去重）、`html-layout-system.md` §9（deck 配额）与 `QA_RUBRIC.md` 反同质化签名核对项。
- **处置动作**：命中页按二次升级判断「改变布局」回路，换用同逻辑下的备选 pattern，或改内容区切分 / 焦点位置 / 模块节奏使四元组至少 2 维不同（禁止只做样式级伪变体）；改后重新登记四元组并复核本条。

**D2. 是否模板感过强？**

- **判定标准**：全 deck 套用单一版式；同场景页面（≥2 页）版式签名雷同（章节页平行一致性为例外）；主题 signature 元素不可见、"看起来只是换色"。任一成立 → 命中。口径引用 `design-scenario-system.md` §4 反模式 1 / 5、`QA_RUBRIC.md` 主题辨识度项与「同场景版式签名不得雷同」检查。
- **处置动作**：按场景卡推荐布局分流重选版式（`design-scenario-system.md` §3），从选型源头拉开版式分布；signature 缺失页回到 art DNA 四类生成背景与主题 token 层修复（`SKILL.md` 运行原则 art DNA 双路径）。

**D3. 是否符合页面场景？**

- **判定标准**：页面场景判定 ∈ 10 类业务场景 + 1 个骨架保留项 `目录页(toc)`（全库唯一口径，`design-scenario-system.md` §2 注），且场景五属性落实——信息密度 / 图片比例落在场景卡量化区间、视觉重点与场景卡一致；数据页无数字焦点、流程页无方向动线、产品介绍页无主体图容器、骨架页堆信息等错配 → 命中。口径引用 `design-scenario-system.md` §2 / §3 与 §4 反模式 3 / 4、`QA_RUBRIC.md` 场景五属性落实项。
- **处置动作**：场景错判页回到总线③重判场景；五属性不落实页按场景卡修正（补数字焦点 / 补方向动线 / 补图片容器）；骨架页信息过载按 §4 反模式 4 压回极低密度档，超密度上限拆页。

## 2. 二次升级判断（逐页强制 · 命中即自动修改）

四维检查 15 条全过后，逐页回答一个问题：**「如果再优化一次，可以通过什么方式让观众更快理解？」** 按以下五种方式依序判定。

**本节是修改动作回路，不是建议清单：命中任一方式即自动执行对应修改动作，禁止只登记建议不动手（自动修改，不只是提出建议）。** 每次修改完成后必须重新执行四维检查（全 15 条），形成闭环，防止改出新问题；五种方式均无命中时，登记「无需升级」结论并写明逐条判否理由（如密度已至场景卡最低档、符号已达每页 ≤2 种纪律上限、焦点已唯一且落在向量终点）。

### 判定顺序与修改动作回路

按「减法优先、结构在后」排序执行；每次只走一种方式的回路，改完即重检。

**U1. 删除文本（减法优先）**

- **判定**：是否存在对主结论无贡献的句子 / 条目（删除测试：删掉后理解不受损）？
- **修改动作回路**：删除该文本 → 核对信息密度降入场景卡档位（`design-scenario-system.md` §2）→ **重过四维检查（全 15 条）**。

**U2. 强化关键词**

- **判定**：主结论数字 / 关键词是否一眼可见（观众 3 秒内可抓取）？是否存在该突出而未突出的结论词 / 核心数字？
- **修改动作回路**：对结论词 / 核心数字施加 `.hl` / `.num` 突出（每页 1–3 处、每卡 ≤3 处，满页高亮视同无高亮；数字必须带口径——`page-logic-patterns.md` §17.1）→ **重过四维检查（全 15 条）**。

**U3. 增加视觉符号**

- **判定**：是否存在纯文字承载的结构关系，可用符号承接后让观众更快读出顺序 / 方向 / 对照 / 层级？
- **修改动作回路**：按 `visual-symbol-system.md` §9 配套表选定符号组合（≤2 种 / 页；结构引导类 accent-2、焦点类 accent）→ 以符号承接关系语义、删去被替代的解释性文字 → **重过四维检查（全 15 条，重点核对 V4 视觉污染）**。

**U4. 调整空间关系**

- **判定**：当前空间关系是否最贴合逻辑类型（查 `spatial-storytelling.md` §7 映射表）？视觉焦点是否落在空间向量终点 / 中心？
- **修改动作回路**：按 §7 表重映射主导空间关系（改排布方向 / 焦点落位；逻辑登记本身需改时回总线④）→ 同步更新蓝图「内容区域」「主视觉区域」字段 → **重过四维检查（全 15 条，重点核对 L1 / L2）**。

**U5. 改变布局**

- **判定**：前四种方式用尽后，理解效率仍可提升（如内容关系与当前 pattern 错位）？
- **修改动作回路**：按 `layout-patterns.md` §13 映射表与冲突裁决规则（资源约束 → 逻辑忠实 → 连页去重 → 焦点唯一 → 容量兜底）重选 pattern / 变体 → 更新 `state/visual_blueprints.md` 该页蓝图九字段（口径 `html-layout-system.md` §0）→ 重渲染该页 → **重过四维检查（全 15 条）**，并复核连页布局签名不撞车（D1）。

### 闭环规则

- **修改后必重检**：每次修改完成后重新执行四维检查全 15 条；重检命中新问题按对应条目的处置动作继续修，同一页最多 3 轮（沿用 `SKILL.md` 阶段 5 修复循环上限）。
- **逐页落盘**：所有终审记录写入 `state/qa_report.md` 终审节——页码 / 四维 15 条结论 / 二次升级命中方式 / 修改内容 / 重检结论（或「无需升级」结论 + 逐条判否理由）。
- **门禁**：任一页缺终审登记、或命中升级方式后只有建议无修改动作，QA 判失败（`SKILL.md` 阶段 5 终审门禁），回到本文件对应回路执行。
