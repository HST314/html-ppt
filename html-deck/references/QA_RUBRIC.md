| 项目 | 分值 | 阻断条件 |
| --- | ---: | --- |

## 文本与符号层检查(新增量化项)

- **对比度硬指标**:正文/背景 ≥4.5:1;有效文字透明度不低于白色 45% 档;accent 填充面上的文字必须为 `--on-accent` 深墨——白字压浅金直接判不合格。
- **关键词/数据突出**:内容页应存在 `.hl` / `.num` 或等效突出样式;数字必须带口径(对比、单位、批次);满页高亮(>3 处/卡)视同无高亮。
- **符号语义核对**:编号/箭头/分界必须承担顺序、方向或对照语义;纯装饰符号每页扣 5 分。
- **结论条真实性**:takeaway 与首条 bullet 逐字相同(机械复制)判不合格,必须为本页主结论的复述或收束。
- **克制卡片**:出现"圆角+左侧色条"卡片、蓝紫渐变、emoji 直接判不合格。
- **反同质化签名核对**:逐页列出 `pattern + 变体` 布局签名,连页相同判失败;≥8 页内容区段版式种类 <5 种判不合格。
- **残留文本**:出现与页面叙事无关的模板腔/占位句(如"试点范围""数据看板"类串场词),或水印/eyebrow 与页面主题无关,判不合格。

## 布局稳定与结构纪律检查(新增量化项)

- **固定 16:9**:deck-stage 计算宽高比与 16/9 偏差 >0.01 判失败;视口缩放必须为等比 scale,禁止非 16:9 拉伸变形。
- **元素不可溢出**:逐页任一元素 `scrollWidth > clientWidth` 或 `scrollHeight > clientHeight` 成立即判溢出失败(打印静态流同样适用);溢出须拆页/归组解决,禁止硬塞。
- **字体不可异常缩小**:1920 画布基准下正文 `getComputedStyle` 字号 <14px 判失败;标题:正文字号比 <2.2 沿用字号层级项判不合格;内容超限先拆页,禁止压缩字号硬塞。
- **图片不可变形**:每个 `<img>` 必须有 `object-fit`(默认 `contain`)与 `alt`;渲染宽高比与 `naturalWidth/naturalHeight` 宽高比偏差 >2%(`contain` 留白边不算变形)判失败。
- **页面间距统一**:页边距实测与 `--slide-padding`(96px,≥86px)偏差 >4px,或同页出现 ≥3 种非标间距值(间距阶梯档:8/14/18/24/32/40),判不合格。
- **反 div 堆叠**:内容页内容区域的直接子级中无 class 的裸 div/纯文本节点占比 >60%,或页面无法分解出「空间结构(Grid/Flex 容器)+ 视觉模块(信息模块/图片区/色块)+ 信息层级(标题/正文/辅助)」三层,判失败。

## 场景判定与场景多样性检查(新增量化项)

- **场景判定记录**:每页必须在 `state/page_semantics.md`「页面场景」列有判定结论(<!-- TASK-010 fix -->枚举 = 10 类业务场景:封面页/章节页/品牌价值页/产品介绍页/项目方案页/流程页/数据页/案例页/成果展示页/总结页 + 1 个骨架保留项 `目录页(toc)`),且蓝图「页面类型」与之一致;任一页缺失即判失败(骨架页不豁免——骨架页场景按故事线位置判定)。
- **蓝图页面类型取值域**:蓝图「页面类型」不在<!-- TASK-010 fix -->「10 类业务场景 + 1 个骨架保留项 `目录页(toc)`」取值域之内 → 判失败;取值口径以 `references/design-scenario-system.md` 为唯一定义,SKILL.md / `html-layout-system.md` / 本文件 / 该文四处一致。
- **选型理由引用场景判定**:蓝图「选型理由」未引用本页场景判定结论(未以"本页为 X 场景……"回答"为什么选择这种设计",仅写"该 pattern 适合此类内容"而无场景名) → 判失败。
- **同场景版式签名不得雷同**:同 deck 内判定为同一场景的页面 ≥2 页时,各页布局签名(pattern + 变体)不得完全相同;章节页平行一致性(重复元素跨页同位)为例外,不算雷同。
- **场景五属性落实**:页面实测信息密度/图片比例超出场景卡量化区间(如骨架页堆信息、数据页无数字焦点、流程页无方向动线),判不合格;超出上限先拆页,禁止压缩硬塞。
- **与既有检查的关系**:场景多样性是事前预防(总线③按场景分流选型),「反同质化签名核对」(连页签名)是事后兜底(总线⑦生成后核对);两层检查都执行,互不替代。

## QA 模式

优先模式：Playwright 打开 HTML，逐页截图，检查 viewport、可见文本、图片自然尺寸与截图导出。

降级模式：无 Playwright 时做结构检查：
- HTML 无外链。
- slide 数等于 IR。
- 每页有标题或封面标题。
- 图片 alt、fit、src 均存在。
- 文本容量未超限。
- 内容页有 action title、takeaway、150 字以上 notes。
- 截图类图片出现 `screenshot-frame`，图片说明来自 manifest description。
- 不含绝对路径。

## 美学首因比对

Playwright 可用时，QA 必须输出逐页截图，并将当前 deck 与 `references/` 中记录的参考 skill 示例页做人工并排检查。以下情况直接判不合格：
- 第一屏缺少明确视觉焦点。
- 内容页截图单独看明显空洞。
- 主题 signature 元素不可见。
- 图片没有遮罩、说明条或截图美化处理。
- 动画先后顺序造成阅读干扰。

# Deck 级阻断门禁

- 第 2 页必须为目录；缺目录不得交付。
- 最后一页必须为 `closing`，且只允许一个标题、至多一个短句和一个 CTA；列表、表格、KPI、takeaway、多图均视为尾页过载。
- 倒数第 2 页必须为独立行动/决策页，不能是封面、目录、章节页或结束页。
- 所有清单图片必须在行动页之前完成展示，图片覆盖率必须为 100%。

## 流程门禁（Deck 级阻断）

本节五条与 `SKILL.md`「流程门禁」（执行流程总线节）逐条一一对应；任一不满足即 QA 判失败，不属于可恢复缺陷。

1. 缺 `context/brief.md` 场景归类结论 → 判失败（总线①「项目理解」缺失）。
2. 缺 `state/storyline.md`，或故事线无目录节点/收束两段式登记 → 判失败（总线②「故事线分析」缺失）。其中：故事线表缺章节序列/叙事任务/页数配额/节奏标注任一列，或收束段未登记两页（行动页 + 结束页），均按本条判失败。
3. `state/page_semantics.md` 任一内容页缺「页面任务」或五步判断任一字段（主结论/信息层级/逻辑关系/视觉结构/视觉焦点）→ 判失败（总线③「页面任务定义」/④「页面逻辑判断」缺失）。**页面逻辑五步判断字段缺失属本条阻断条件。**
4. 缺 `state/visual_blueprints.md` 或内容页蓝图九字段（<!-- TASK-007 fix: 七字段与八字段合并为一份定义，与 SKILL.md / html-layout-system.md §0 同口径 -->页面类型/主视觉区域/标题区域/内容区域/辅助区域/图片区域/留白区域/SVG需求/选型理由）任一空缺 → 判失败（总线⑤「视觉结构选择」缺失）。**visual_blueprints 九字段缺失属本条阻断条件。**
