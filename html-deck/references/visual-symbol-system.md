# VISUAL SYMBOL SYSTEM（视觉符号系统）

本文件定义 html-deck 的**视觉符号系统**：编号、箭头、节点、路径、标签、连接线、标记七类符号的语义职能、使用场景、实现方式与纪律。所有符号必须承担以下**四种语义职能**中的一种或多种——**方向 / 关系 / 重点 / 层级**；一种都不承担的符号即纯装饰，按 §8 判定规则清除。

与其他文档的分工（互不替代）：

- `spatial-storytelling.md`：定"空间方向表达什么语义"（六组空间关系）；**本文件**定"用什么符号承接这些语义"。两文配套使用——先定空间关系，再选符号。
- `page-logic-patterns.md` §17.2：既有符号视觉引导轻量件清单（编号徽章 / 字符箭头 / 发丝线 / 中央分界徽标 / 回授符）。本文件将其扩展为七类符号的完整系统；语义纪律（符号必须承担逻辑语义、每页符号体系 ≤2 种）与之保持一致，不另立口径。
- `layout-patterns.md` 铁律：符号引导轻量件清单（纯 CSS 优先）、每页符号体系 ≤2 种、重 SVG 件（环形、描边动线）只用于闭环与封面 / 章节。
- `THEMES.md` 双色分工：accent = 强调与焦点；accent-2 = 结构与引导（编号、连接线、符号）——符号取色的唯一口径，禁止第三强调色。
- `QA_RUBRIC.md`「文本与符号层检查」：符号语义核对（纯装饰符号每页扣 5 分）——本文件 §8 给出"纯装饰"的可执行判定标准与正误示例。

## 0. 总则

### 0.1 四种语义职能（符号存在的唯一理由）

| 职能 | 定义 | 典型符号 |
| --- | --- | --- |
| **方向** | 指示阅读 / 推进方向：从哪里来、到哪里去 | 箭头、路径、编号递增 |
| **关系** | 指示元素间关系：连接、对照、包含、辐射、归属 | 连接线、节点、标签、标记 |
| **重点** | 指示视觉焦点 / 关键信息：看这里 | 焦点节点、标记、放大编号 |
| **层级** | 指示等级 / 顺序：谁先谁后、谁高谁低 | 编号、L1–Ln、组标题标签 |

### 0.2 符号上板三问（每个符号必须逐问通过）

1. 它承担四种语义职能中的哪一种（或哪几种）？——答不出 → 纯装饰。
2. 删掉它，观众对页面逻辑的理解是否会受损？——不受损 → 纯装饰。
3. 它的指向 / 连接对象是否真实存在于页面上？——指向虚空 → 纯装饰。

### 0.3 用量与样式纪律

- 每页符号体系 **≤2 种**（如编号 + 箭头），防止视觉噪音（沿用 `layout-patterns.md` 铁律与 `page-logic-patterns.md` §17.2）。
- 纯 CSS 轻量件优先（字符箭头、编号徽章、发丝线）；重 SVG 件（环形、描边动线）只用于闭环与封面 / 章节页。
- 取色：结构与引导类符号（编号、箭头、连接线、路径）用 **accent-2**；焦点类符号（焦点节点、重点标记）用 **accent**；反色面上的符号文字走 `--on-accent`（`THEMES.md` 深色纪律）。
- 符号语义必须与 `state/page_semantics.md` 登记的主导逻辑一致（如并列逻辑页面不得出现推进箭头）。

## 1. 编号（number badge）

- **语义职能**：层级 + 方向——编号把顺序与等级外化，观众不看正文也知道结构与先后（`page-logic-patterns.md` §16「显式编号建立秩序」）。
- **使用场景**：流程 / 递进节点（01–N）、层级分层（L1–Ln）、目录章节编号、主图细节槽编号（1–3）、⑨ 变体 ed-strip 的大编号徽章。
- **实现**：mono 字重 900、accent-2 描边 / 底色徽章（CSS counter 实现，见 `html-layout-system.md` §5 编号徽章模块）；次级序号同用 accent-2。编号取色不设例外——编号属结构与引导类符号，按 §0.3 与 `THEMES.md` 双色分工唯一口径走 accent-2，两色职责不交叉。
- **禁止事项**：禁止给无顺序语义的平等条目挂编号（伪造流程）；编号计数必须与实际渲染节点数一致（计数变体 ascend-N / chain-N / loop-N 门禁，见 `SKILL.md` 视觉布局决策引擎门禁）；禁止编号断号、重号。

## 2. 箭头（arrow）

- **语义职能**：方向（主）+ 关系——表达推进方向、因果推导（因→果）、聚合指向、闭环回授。
- **使用场景**：流程链节点之间、因果页左因右果、外围→中心聚合指向、闭环回授符（↺）。
- **实现**：字符箭头 `→` / `↓` 优先（accent-2 色，`flex-shrink:0` 不被压缩，见 `html-layout-system.md` §2）；长距跨区或环形走向用细线 SVG 箭头。
- **禁止事项**：禁止无指向对象的装饰箭头（指向空白即 §8 纯装饰）；禁止箭头方向与页面主导空间关系冲突（左→右时间推进页画 `←`）；禁止一页混用两种以上箭头样式（字符 / 三角 / 手绘混用）。

## 3. 节点（node）

- **语义职能**：关系 + 重点 + 层级——节点是流程 / 生态 / 层级结构中的信息站位，节点大小与样式差异表达主次。
- **使用场景**：流程节点卡、中心辐射分支卡、时间轴事件点、闭环环节点。
- **实现**：信息模块（卡片 / 栏，`html-layout-system.md` §5）；焦点节点按版式规则放大（如时间轴"现在"节点可放大 1.2–1.5 倍，`layout-patterns.md` ④）或使用 accent 面（全页仅一个 accent 焦点面，沿用 §17.4 克制卡片纪律）。
- **禁止事项**：禁止无内容的空节点 / 补位幻影节点（渲染层不得把 IR 补位块落成节点卡片，`SKILL.md` 计数变体门禁）；禁止节点样式与同链节点无差别却在蓝图中登记为焦点（焦点必须可辨识：最大字号 / 最大面积 / 最高对比至少居一）。

## 4. 路径（path）

- **语义职能**：方向 + 关系——路径线 = 流程（`spatial-storytelling.md` §5），线的走向即推进方向，观众沿线阅读即完成流程理解。
- **使用场景**：流程动线（横轴 / 阶梯 / 折线）、闭环环形路径、时间轴主轴、聚合收束线。
- **实现**：轻量路径用 Flex 链 + 字符箭头（节点 `flex:1` + 箭头 `flex-shrink:0`）；闭合环形、描边动线用 SVG（仅闭环与封面 / 章节页）；阶梯抬升基线用于递进 ascend 变体。
- **禁止事项**：禁止不串联任何节点的孤立曲线 / 线条（纯装饰线条的最典型形态，§8 判定）；禁止路径断裂、无终点、方向不可读（既无箭头也无编号递增）；禁止路径穿过文字阅读区。

## 5. 标签（label / tag）

- **语义职能**：层级 + 关系——标签表达分组归属与信息层级（组标题、维度标注、章节归属）。
- **使用场景**：信息组组标题（≤10 字名词短语，必须在页面上可见，`page-logic-patterns.md` §15）、kicker / eyebrow（项目代号）、矩阵象限的维度轴标注、pill 标签行、图片 caption。
- **实现**：mono 小字（kicker / eyebrow）或 `.h2` 组标题；pill 行走 §2 Flex `.row`（`html-layout-system.md`）。
- **禁止事项**：禁止与页面主题无关的水印词 / 占位标签（DECK / LOREM 等无意义词，残留文本纪律见 `page-logic-patterns.md` §17.5）；禁止标签下无对应信息组（空分组标签即关系造假）；禁止标签层级超过页面信息层级（标签字号不得压过组标题）。

## 6. 连接线（connector）

- **语义职能**：关系（主）+ 方向——表达两个真实元素之间的派生、呼应、对照关系。
- **使用场景**：中心核与分支间的辐射连接线（① 中心节点+分支）、主图与细节槽之间的呼应引线（⑪ 主图+细节）、卖点与产品主体间的标注引线（⑩ 产品英雄图）。
- **实现**：细线 SVG 或 1px 发丝线（`--line` token），accent-2 色；引线端点落在元素边界，不压字。
- **禁止事项**：禁止两端不同时落在真实元素上的线（一端悬空即 §8 纯装饰）；禁止走线交叉超过 2 次（先改布局再画线）；禁止粗重分隔条充当连接线（分隔只用 1px 发丝线，`page-logic-patterns.md` §17.2）。

## 7. 标记（marker）

- **语义职能**：重点 + 关系（对位）——标记锁定对照位置或焦点位置，是"看这里 / 从这里分界"的空间锚点。
- **使用场景**：⑤ 对比构图的中央分界徽标（竖线 + VS / 节点圆）、时间轴"现在"节点的放大标记、矩阵象限的目标点标记、地图 / 示意图上的位置标记。
- **实现**：中央分界徽标（compare pattern 组件）、节点圆点、象限轴刻度；焦点标记用 accent 面 + `--on-accent` 文字。
- **禁止事项**：禁止与对照维度无关的装饰徽标（不参与对位的 VS 类徽章即纯装饰）；禁止标记指向不存在的对位关系（如单侧内容页放分界标记）；禁止同页多个焦点标记（焦点唯一，`page-logic-patterns.md` §14）。

## 8. 禁止纯装饰线条（判定标准 + 正误示例）

**判定标准**（逐条测试，任一命中即判为纯装饰线条，必须删除或改造为语义符号）：

1. **语义测试**：该线条 / 符号不表达方向、关系、重点、层级中任何一种职能（§0.2 三问之第 1 问答不出）。
2. **删除测试**：删掉它之后，观众对页面逻辑的理解不受任何损失（§0.2 三问之第 2 问）——"看着更饱满"不算损失。
3. **锚点测试**（按线型分两款执行）：
   - **连接线 / 路径 / 箭头**：线条两端（或指向端）必须同时落在页面真实元素上——悬空线、穿场曲线、无指向的箭头判失败。
   - **分隔线**：必须真实分隔两个已登记信息组 / 对照区（线的两侧各有一个可见、已登记的信息组或对照内容）——无分组对象的分隔线（如标题下与内容等宽、下方并无分组对象的装饰条）判失败。

QA 执行口径：逐页对每个线条 / 符号跑三条测试（锚点测试按线型选对应款执行），命中任一即按 `QA_RUBRIC.md`「文本与符号层检查」符号语义核对项处理（纯装饰符号每页扣 5 分）；整页线条全部未命中方可通过。

**正误示例**：

| # | 场景 | ✓ 正确（承载语义） | ✗ 错误（纯装饰） |
| --- | --- | --- | --- |
| 1 | 流程页 | 节点间 `→` 串联 01→02→03，表达推进方向与先后关系 | 页面底部一条波浪曲线"活跃气氛"，不串联任何节点 |
| 2 | 中心辐射页 | 中心核到各分支的细线，表达派生 / 连接关系 | 四角放射状光线当"科技感"背景，两端不落任何元素 |
| 3 | 分组边界 | 信息组之间 1px `--line` 发丝线，两侧各为一个已登记信息组，真实分隔两组、表达分组边界（过锚点测试分隔线款） | 标题下与内容等宽的渐变彩条，下方并无分组对象，不分隔任何信息组（锚点测试分隔线款判失败） |
| 4 | 对比页 | ⑤ 对比构图中央竖线 + VS 徽标，表达两侧对位与分界 | 页边斜切色带仅作"动感"装饰，不构成任何对位 |
| 5 | 聚合页 | 外围要素指向中心结论核的箭头，表达汇聚方向 | 文字下方随手画的下划线 / 小箭头，无所指对象 |
| 6 | 层级页 | L1–Ln 编号 + 层间发丝线，表达层级与分层边界 | 塔形剪影背景叠在分层条后面"烘托氛围"，无层级对应 |

## 9. 符号 × 语义职能矩阵（与空间关系的衔接）

| 符号 | 方向 | 关系 | 重点 | 层级 | 首选落点（pattern） |
| --- | :-: | :-: | :-: | :-: | --- |
| 编号 | ● | ○ | ○ | ● | ③ 路径式流程、④ 时间轴、⑫ 层级空间结构、目录页 |
| 箭头 | ● | ● | ○ | ○ | ③ 路径式流程、⑨ 非对称图文（因果）、② 三模块闭环 |
| 节点 | ○ | ● | ● | ● | ① 中心节点+分支、③ 路径式流程、② 三模块闭环 |
| 路径 | ● | ● | ○ | ○ | ③ 路径式流程、② 三模块闭环、④ 时间轴 |
| 标签 | ○ | ● | ○ | ● | 全部 pattern（组标题 / kicker / 维度标注） |
| 连接线 | ● | ● | ○ | ○ | ① 中心节点+分支、⑩ 产品英雄图、⑪ 主图+细节 |
| 标记 | ○ | ● | ● | ○ | ⑤ 对比构图、④ 时间轴、⑦ 矩阵 |

（● = 主要职能，○ = 可承担职能）

**与六组空间关系的符号配套**（空间关系定义见 `spatial-storytelling.md` §1–§6；选型顺序：主导逻辑 → 空间关系 → 本表符号组合 → token 取色）：

| 空间关系 | 语义 | 推荐符号组合（≤2 种 / 页） |
| --- | --- | --- |
| 左 → 右（时间推进） | 推进方向 + 顺序 | 编号 + 箭头（时间轴页可加"现在"标记，作为第 2 种内的焦点件） |
| 上 → 下（层级关系） | 等级 + 分组边界 | L 编号 + 标签（层间发丝线属连接线；与 ≤2 种规则冲突时去线留编号） |
| 中心 → 周围（生态关系） | 派生关系 + 中心焦点 | 节点 + 连接线 |
| 外围 → 中心（聚合过程） | 汇聚方向 + 结论焦点 | 箭头 + 节点（中心焦点节点即重点件） |
| 路径线（流程） | 推进方向 + 顺序 + 站位 | 编号 + 箭头（路径本体由 Flex 链 / SVG 动线承载） |
| 对比布局（变化） | 对位关系 + 分界重点 | 标记 + 标签（维度行标注） |

## 10. QA 核对点（汇总）

| 核对点 | 判定口径 | 位置 |
| --- | --- | --- |
| 符号语义职能登记 | 每页所用符号能归入四种语义职能；归入不了即纯装饰（§8 测试 1） | 逐页目视 |
| 纯装饰线条零命中 | 逐线条跑 §8 三条测试，命中任一即扣分 / 改造 | `QA_RUBRIC.md` 符号语义核对 |
| 每页符号体系 ≤2 种 | 超出即视觉噪音，先减符号再落版 | 逐页目视 |
| 取色合规 | 结构引导类 accent-2、焦点类 accent、反色面 `--on-accent`；无第三强调色 | `THEMES.md` 双色分工 |
| 编号 / 节点计数一致 | 计数变体 N = 蓝图登记数 = 实际渲染节点数；无幻影节点 | `SKILL.md` 计数变体门禁 |
| 与空间关系一致 | 符号组合与本页主导空间关系命中 §9 配套表；逻辑冲突（并列页画推进箭头等）判失败 | `spatial-storytelling.md` §7 |
